# Excel 输入输出路径变更设计

## 目标

将现有同步结果作为下一次同步的输入，并生成一个新文件，避免覆盖输入文件。

## 配置变更

仅修改 `config.json` 中的两个字段：

- `input`：改为 `outputs/26年8月分级总表_API同步.xlsx`
- `output`：改为 `outputs/26年8月分级总表_API再次同步.xlsx`

两个路径均相对于 `config.json` 所在目录解析。日期、Cookie、货号清单、别名、报告目录和其他运行参数保持不变。

## 验证

修改后解析 `config.json`，确认文件是有效 JSON；解析输入路径并确认源 Excel 存在；确认输入与输出不是同一路径。
